# Hi, I'm Shlomi Saadon

I'm a full-stack developer and founder of iPromotion. I build web and mobile products, developer tools, and business automations.

My public GitHub work goes back to 2021, with projects in HTML, CSS, JavaScript, React, Angular, and Firebase. Today I also work with TypeScript and Flutter, connecting product interfaces to backend services and business workflows.
